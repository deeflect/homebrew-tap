# deeflect Homebrew Tap

Official Homebrew Casks for macOS apps by [Dmitry (Dee) Kargaev](https://www.deeflect.com) ([dee.agency](https://www.dee.agency)).

## Install

```bash
brew tap deeflect/tap
```

| App | Install | What it does | Site |
|---|---|---|---|
| **chort** | `brew install --cask deeflect/tap/chort` | Local HTML/CSS design canvas driven by Claude Code & Codex over MCP | [chort.design](https://chort.design) |
| **Genvas** | `brew install --cask deeflect/tap/genvas` | Desktop node canvas for AI image, video, audio & 3D pipelines (BYO keys + local MCP) | [genvas.app](https://genvas.app) |
| **Herdtrude** | `brew install --cask deeflect/tap/herdtrude` | Desktop & menu-bar monitor for parallel Claude Code, Codex, Cursor & OpenCode sessions | [herdtrude.app](https://herdtrude.app) |
| **Typeset** | `brew install --cask deeflect/tap/typeset` | Native Swift Markdown reader with live reload, Quick Look & Typst PDF export (AGPL-3.0) | [typeset.md](https://typeset.md) |
